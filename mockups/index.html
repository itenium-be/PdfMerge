Three ways to build the PDF tool

Same feature set — merge, reorder, split, delete, replace — and the same shell as the QR Generator: light/dark, itenium footer, source on GitHub. What differs is the model the user has to hold in their head. Every mockup is clickable: reorder, cut, select, switch outputs.
